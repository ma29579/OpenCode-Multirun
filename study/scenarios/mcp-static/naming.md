# Naming

- **DB-01 Table names** are lowercase `snake_case` and **plural**: `horses`, `cows`, `stables`, `feeds`.
- **DB-02 Column names** are lowercase `snake_case`: `daily_milk_liters`, `birth_date`. No camelCase, no quoted identifiers, no table prefix.
- **DB-03 Primary key** is a single column named `id`, type `BIGINT`, generated by the database (identity).
- **DB-04 Foreign keys** are named `<referenced_table_singular>_id` (e.g. `stable_id`) and are real database foreign keys.
- **DB-05 Constraint and index names** are explicit and follow a pattern: `pk_<table>`, `fk_<table>_<column>`, `uq_<table>_<column>`, `idx_<table>_<column>`.
- **DB-06 No reserved words** as table or column names (`order`, `group`, `desc`, `year`, ...).
- **STD-02 Name composite objects completely.** Names of composite indexes and unique constraints list all columns in their order: `idx_<table>_<column1>_<column2>`, `uq_<table>_<column1>_<column2>`. Abbreviated or summarized column names are not allowed.
- **STD-07 Boolean columns** are named as a statement with the prefix `is_` or `has_` (`is_active`, `has_horns`). A bare adjective such as `active` or `horned` is not allowed.
- **STD-08 Date and time columns** carry their type in the name: `TIMESTAMP` columns end with `_at` (`delivered_at`), `DATE` columns end with `_date` or `_on` (`birth_date`, `hired_on`). Names such as `since`, `born` or `date` are not allowed.
- **STD-09 Measured quantities end with their unit** (`weight_kg`, `height_cm`, `interval_days`, `daily_milk_liters`). A bare `weight` or `amount` is not allowed.
- **STD-10 Money columns end with the currency code in lowercase** (`total_price_eur`, `price_per_kg_eur`). A bare `price`, `cost` or `total` is not allowed.
- **DES-01 Table names** are singular and start with the prefix `tbl_` (`tbl_pig`, `tbl_stable`, `tbl_feed`).
- **DES-02 Column names** use `camelCase` (`ageInMonths`, `targetWeightKg`). Columns are quoted in SQL where the database requires it.
- **DES-03 Primary keys** are named `<entity>Id` (`pigId`, `stableId`) and are 32-bit integers.
- **DES-04 Constraint and index names** are generated by the database. Explicit names are not required.
