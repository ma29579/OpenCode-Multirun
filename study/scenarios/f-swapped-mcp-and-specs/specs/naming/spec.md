# Naming Specification

## Purpose

How tables, columns, keys, constraints, indexes and flags are named.

## Requirements

### Requirement: DB-01 Table names

Table names are lowercase `snake_case` and **plural**: `horses`, `cows`, `stables`, `feeds`.

### Requirement: DB-02 Primary key

Primary key is a single column named `id`, type `BIGINT`, generated by the database (identity).

### Requirement: DB-03 Foreign keys

Foreign keys are named `<referenced_table_singular>_id` (e.g. `stable_id`) and are real database foreign keys.
