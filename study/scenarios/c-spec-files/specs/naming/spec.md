# Naming Specification

## Purpose

How tables, columns, keys, constraints, indexes and flags are named.

## Requirements

### Requirement: DB-01 Table names

Table names are lowercase `snake_case` and **plural**: `horses`, `cows`, `stables`, `feeds`.

### Requirement: DB-02 Primary key

Primary key is a single column named `id`, type `BIGINT`, generated by the database (identity).

### Requirement: DB-03 Foreign keys

Foreign keys are named `<referenced_table_singular>_id` (e.g. `stable_id`) and are real database foreign keys.

### Requirement: STD-02 Name composite objects completely

Name composite objects completely. Names of composite indexes and unique constraints list all columns in their order: `idx_<table>_<column1>_<column2>`, `uq_<table>_<column1>_<column2>`. Abbreviated or summarized column names are not allowed.

### Requirement: STD-06 Boolean columns

Boolean columns are named as a statement with the prefix `is_` or `has_` (`is_active`, `has_horns`). A bare adjective such as `active` or `horned` is not allowed.

### Requirement: STD-07 Date and time columns

Date and time columns carry their type in the name: `TIMESTAMP` columns end with `_at` (`delivered_at`), `DATE` columns end with `_date` or `_on` (`birth_date`, `hired_on`). Names such as `since`, `born` or `date` are not allowed.

### Requirement: STD-08 Measured quantities end with their unit

Measured quantities end with their unit (`weight_kg`, `height_cm`, `interval_days`, `daily_milk_liters`). A bare `weight` or `amount` is not allowed.

### Requirement: STD-09 Money columns end with the currency code in lowercase

Money columns end with the currency code in lowercase (`total_price_eur`, `price_per_kg_eur`). A bare `price`, `cost` or `total` is not allowed.

### Requirement: DES-01 Table names

Table names are singular `snake_case`: `horse`, `stable`, `feed`.

### Requirement: DES-02 Primary keys

Primary keys are named `<table>_id` (`horse_id`, `stable_id`) and are of type `UUID`, generated by the database with `gen_random_uuid()`.

### Requirement: DES-03 Boolean columns

Boolean columns are named as a plain adjective or noun without a prefix (`active`, `horned`, `newsletter`).

### Requirement: DES-04 Money columns

Money columns do not carry a currency suffix (`total_price`, `price_per_kg`); the currency of the farm is EUR everywhere.
